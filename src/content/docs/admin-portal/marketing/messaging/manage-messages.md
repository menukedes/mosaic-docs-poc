All your messages, from drafts to completed campaigns, are listed under **Marketing** → **Messaging**.

## Find your messages

1. In the Admin Portal, select **Marketing** from the left menu.
2. Select the **Messaging** tab.

The list shows each message with its status and separate email and push recipient counts. Use **Filter Status By** to narrow the list, and **Refresh** to update statuses while messages are sending.

## Edit a draft or scheduled message

1. Open the message's action menu and select **Edit Message**.
2. Make your changes. Check the **Recipients** again, since they need to be chosen on purpose.
3. Send it, schedule it, or select **Save as Draft**.

Messages that are **In Progress** or **Completed** can't be edited.

## Reuse a sent message

1. Open the message's action menu and select **Clone Message**.
2. Update the content, choose the **Recipients** and set the timing.
3. Send or schedule it as usual.

:::tip
Cloning is a quick way to run a recurring campaign, such as a weekly deal email, with the same template and layout.
:::

## Delete a draft

1. Open the draft's action menu and select **Delete Draft Message**.
2. Confirm.

Only drafts can be deleted. Sent and scheduled messages stay in the list as a record.

## Check results

Open a message to see its **Message Statistics**, with separate sections for email and push notifications. Statistics appear once the message has finished sending.

:::note
Check a campaign's statistics within a few weeks of sending. Statistics for older campaigns may not be available.
:::
